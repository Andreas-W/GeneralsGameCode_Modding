This site documents what the [GeneralsGameCode_Modding](https://github.com/Andreas-W/GeneralsGameCode_Modding)
fork adds to the Zero Hour engine for modders: new modules and INI fields, new enum values, raised
limits and fixed engine bugs. Everything here is about Zero Hour.
